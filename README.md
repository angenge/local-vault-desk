# LocalVaultDesk (本地文件保险箱)

基于 **Tauri 2.0 (Rust) + Vue 3 + Rclone crypt (librclone 静态链接)** 构建的纯本地、零云端依赖的 Windows 私密文件保险箱。加密引擎以内置 `librclone.a`（rclone v1.68.2）纯内存 FFI 方式常驻主进程，无子进程、无网络端口、无临时可执行文件。

## 核心特性

- **纯本地离线**：不依赖任何第三方云服务，密文库完全存放在本地自选目录。
- **纯单文件绿色运行**：主程序已全面静态链接 `librclone.a` 与 `WebView2Loader`，完全无需携带任何外部动态库 DLL。
- **高强度透明加密**：
  - 文件内容采用 **XSalsa20 + Poly1305** 分块加密（块大小 64 KiB）。
  - 文件名及文件夹目录采用 **AES-EME-128 (`standard`)** 强混淆，隐藏文件真实名称、层级与文件长度。
- **密钥派生（确定性，可跨机互通）**：以 `账号 + 主密码` 经 **PBKDF2-HMAC-SHA512（100,000 次迭代，32 字节）** 派生 rclone 所需的 `password` 与 `password2` 两个独立 hex 密钥；仅注入内存，**零配置文件落盘**，随用随销毁。
- **安全防丢机制**：**只读原文件，绝不主动删除**；加密导入完成后弹出安全提醒，由用户确认后手动 `Shift+Delete` 原文件。
- **完整文件管理**：导入（文件/文件夹/拖拽）、目录导航、多选操作、剪切/复制/粘贴、重命名、移入回收站。
- **解密导出**：单选或 **批量多选**，带实时进度、速度与取消；导出即完整明文还原。
- **全库搜索**：按文件名/目录名即时检索（本地缓存索引，加密内容不参与全文检索）。
- **回收站**：误删可恢复，支持彻底清空。
- **保险箱工具抽屉**：完整性自检（SHA1 指纹清单 + 逐文件校验）、统计面板、审计日志。
- **外部 rclone 互通**：一键导出与当前保险箱等价的标准 `[interop_crypt]` 配置段，并支持校验「外部 rclone 写入的文件能否被本保险箱解密读取」。
- **安全增强**：闲置自动锁定、传输中取消、非法/保留名称前端后端双重校验、回收集/完整性/密钥驻留管理等。

## 自动化构建与发布

- 项目配置了 GitHub Actions 自动化 CI/CD 工作流。
- 当向仓库推送版本标签（例如 `git tag v1.0.0 && git push origin v1.0.0`）时，将自动完成全链路静态编译、全套 E2E/安全/Fuzz 验证，并将便携版压缩包与安装包自动发布至 GitHub Releases。
