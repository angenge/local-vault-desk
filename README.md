# LocalVaultDesk（本地文件保险箱）

> 把敏感文件放进你自己的保险箱——本地加密、离线可用、随取随用。

**LocalVaultDesk 是一个纯本地的 Windows 私密文件保险箱**：高强度加密引擎内置在主程序之中，不依赖任何云服务，密文存放在你指定的本地目录。文件进入保险箱即被加密，浏览、搜索、导出前再透明解密——全程离线，不留明文痕迹。

## 你是否面临这些问题？

- **电脑与家人/同事共用**：换个账号、插个系统盘，你的文件夹随时可能被人点开。
- **笔记本丢失或送修**：设备不在身边，就等于数据不在身边。
- **敏感文件想上云盘**：能加密上传的，解密密钥却往往掌握在别人手里。
- **试过文件夹加密/隐藏工具**：看起来安全，一旦重装系统、进 PE 或拆下硬盘，保护立刻形同虚设。

LocalVaultDesk 把这些威胁一次性兜住：密文对任何系统、任何工具都不可读，钥匙只在你脑子里。

## 它能帮你做什么

- **放置身份与财产资料**：身份证/护照扫描件、合同、银行卡信息、密钥备份、授权书等。
- **收纳私人内容**：私人照片、聊天记录导出、个人笔记等不想被他人翻到的文件。
- **上传前先加密**：重要文件在交给他人或上传云盘前，本地先加密一层。
- **统一管理工作敏感文件**：项目密钥、开发凭据、客户资料，按保险箱目录整理。

## 为什么值得信赖

- **零云端、可离线**：文件不出本机，无第三方服务器，断网也能用。
- **真加密，不是锁目录**：普通「文件夹加密」只是加个锁，懂行的人绕过系统就能看。这里的内容以 **XSalsa20 + Poly1305** 分块加密（64 KiB 块），文件名与目录结构以 **AES-EME-128** 强混淆——即使整盘拷走，也在密文上翻不出任何真实名称、层级结构与文件长度，等同于一堆无意义乱码。
- **密码学级密钥派生**：`账号 + 主密码` 经 **PBKDF2-HMAC-SHA512（100,000 次迭代）** 确定性派生加密密钥。密钥仅驻留内存、随用随毁，**零配置文件落盘**，锁定/退出即彻底清除；暴力破解的成本远超你能承受的范围。
- **防丢设计**：只读你的原文件，加密导入完成后由你确认再手动删除；误删文件可进回收站恢复。
- **单文件绿色运行**：加密内核与程序静态链接为一体，解压即用、无需安装。

## 核心功能

| 能力 | 说明 |
| :--- | :--- |
| 导入加密 | 支持文件/文件夹/拖拽导入，原文件只在加密完成后由你确认删除 |
| 浏览管理 | 目录导航、多选、剪切/复制/粘贴、重命名、右键菜单与快捷键 |
| 解密导出 | 单选或批量导出，实时进度/速度/可取消，导出即完整明文还原 |
| 全库搜索 | 按文件名/目录名即时检索（加密内容不参与全文搜索，锁定即失效） |
| 回收站 | 误删可恢复，支持彻底清空 |
| 内置预览与流媒体 | 内存安全预览（200 MB 熔断）；可启动局域网 HTTP 流式服务，手机扫码即播 |
| 完整性自检 | SHA1 指纹清单 + 逐文件校验，发现密文库是否被篡改 |
| 统计与审计 | 统计面板 + 审计日志，掌握保险箱整体情况 |
| 外部 rclone 互通 | 一键导出等价 crypt 配置段，让既有 rclone 直接读写同一密文库 |
| 安全增强 | 闲置自动锁定、传输中取消、非法/保留文件名前后端双重校验、密钥驻留管控 |

## 快速上手

1. 下载 `本地文件保险箱_v1.0.0_便携版.zip`（或 NSIS/MSI 安装包），解压即用，无需安装。
2. 首次使用：选择密文存放目录 → 创建账号与主密码 → 建立保险箱。
3. 之后解锁输入「账号 + 主密码」即可进入。

> ⚠️ **账号与主密码是唯一钥匙，系统不落盘存储，务必牢记。** 一旦遗忘，密文将无法恢复。

## 从源码构建

环境：Windows 10/11 x64；需 Node.js ≥ 18、Go ≥ 1.22、Rust（`x86_64-pc-windows-gnu`）与 MinGW-w64（可参考 [BUILD.md](BUILD.md)）。

```powershell
cd src-tauri\librclone_src
go build -buildmode=c-archive -o ..\lib\librclone.a .
cd ..\..

npm install
npm run build
npx tauri build
```

## 技术架构（简版）

- **宿主**：Tauri 2.0 (Rust)；**前端**：Vue 3 + TypeScript + Tailwind CSS。
- **加密引擎**：rclone crypt v1.68.2 以静态链接库 `librclone.a` 纯内存 FFI 方式常驻主进程——无子进程、无临时可执行文件，调用微秒级响应。
- **默认不对外暴露服务**：仅当主动启用内置预览/局域网流媒体时，才在本机（或可选的局域网）启动 HTTP 服务。
